Shared HTTP client for all GoaT API requests. A shared HTTP client for all GoaT API requests.

GoatClient wraps reqwest::Client so the underlying connection pool is created once and reused across all concurrent requests instead of being rebuilt on every call. Clone it freely — the inner client is reference-counted.

MAX_CONCURRENT_REQUESTS
The most requests to have in flight at once, so that large batches (e.g. a -f file of 500 taxa) don’t flood the GoaT API.

concurrency
How many of n requests to run at once: at most MAX_CONCURRENT_REQUESTS, and at least 1 (buffered(0) never completes).
