The cli itself The command line interface, defined with clap’s derive API.

Each subcommand’s arguments are a typed struct, so the code using them is checked at compile time.

Help text is given with explicit help = ... attributes rather than doc comments, because clap derive turns doc comments on these types into (long) help, which would change the --help output.
